# Contributing

Keep changes focused and describe the behavior they change. Run core tests in Debug and Release, build both supported platform families, and run the native workflow for interface changes. Document checks that require physical hardware.

Preserve originals, bound decoding before allocating image buffers, and keep expensive work outside the main actor. Do not commit personal photos, signing identities, provisioning profiles, credentials, or machine-specific Xcode state. Add no network service without explaining its data handling and updating the privacy documentation.
